# Agent Creation documentation index

This folder is the persistent project record for the companion-focused SAP fork, not a separate executable application.

Start here, in order:

1. [PROJECT_CHARTER.md](PROJECT_CHARTER.md) — goals, boundaries, architecture and milestones.
2. [WORK_PROTOCOL.md](WORK_PROTOCOL.md) — non-negotiable practices for future coding work.
3. [FEATURE_MATRIX.md](FEATURE_MATRIX.md) — retain/hide/remove decisions and planned interface.
4. [LOCALIZATION_POLICY.md](LOCALIZATION_POLICY.md) — comprehensive English conversion rules.
5. [REFERENCE_RESEARCH.md](REFERENCE_RESEARCH.md) — pinned community sources and licensing.
6. [UPSTREAM_TRACKING.md](UPSTREAM_TRACKING.md) — exact upstream source comparison.
7. [CHANGE_LEDGER.md](CHANGE_LEDGER.md) — append-only, fine-grained changes and evidence.
8. [RELEASE_AND_TEST.md](RELEASE_AND_TEST.md) — smoke tests, build command semantics, archives.
9. [DECISIONS.md](DECISIONS.md) — architecture decisions and rationale.

The repository root [AGENTS.md](../../AGENTS.md) directs code agents to this folder. Documentation states intended behavior unless explicitly marked implemented/tested. Do not mistake a plan or a source inspection for a working feature.

**Current state: bootstrap documentation only.** SAP itself is not yet converted to English-only and its UI has not been reworked. The upstream AGPL-3.0 license and notices remain in force.
